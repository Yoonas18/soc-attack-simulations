# Azure RDP Brute Force Attack Investigation

## Overview

This report documents the investigation of a brute-force attack targeting a Windows virtual machine hosted in Microsoft Azure.
The attack was detected by monitoring authentication logs generated by repeated Remote Desktop Protocol (RDP) login attempts.

The objective of this investigation was to analyze the attack behavior, identify indicators of compromise, and simulate a SOC-style incident investigation workflow.

---

## Lab Environment

Cloud Platform: Microsoft Azure (Free Tier)
Target System: Windows Virtual Machine
Access Service: Remote Desktop Protocol (RDP)
Monitoring: System authentication logs

---

## Attack Description

After deploying the Windows virtual machine in Azure, multiple failed RDP authentication attempts were observed within a short period of time.

The activity indicated a possible brute-force attack attempting to guess user credentials through repeated login attempts.

---

## Observed Indicators

Example log events:

* Multiple failed login attempts
* Same source IP performing repeated authentication attempts
* High frequency of login failures within a short time window

Example event pattern:

Failed RDP login attempt
Source IP: External attacker IP
Target user: Administrator

These repeated authentication failures suggested automated credential guessing.

---

## Investigation Process

1. Monitored Windows authentication logs from the Azure virtual machine.
2. Identified repeated login failures targeting the same account.
3. Correlated timestamps of login attempts.
4. Observed a high volume of authentication attempts within a short time period.
5. Determined the activity matched a brute-force attack pattern.

---

## Detection Method

Indicators used for detection:

* Multiple authentication failures from a single IP address
* High login attempt frequency
* Repeated targeting of administrative accounts

This pattern is commonly associated with automated password guessing tools.

---

## Impact Assessment

No successful authentication was observed during the attack simulation.

However, such attacks may eventually succeed if:

* weak passwords are used
* RDP is exposed to the internet
* rate limiting is not implemented

---

## Mitigation Recommendations

Recommended security measures include:

* Disable direct RDP exposure to the internet
* Implement Network Security Group rules to restrict access
* Use strong password policies
* Enable multi-factor authentication
* Deploy intrusion detection monitoring
* Implement account lockout policies

---

## Lessons Learned

This simulation demonstrates how exposed RDP services on cloud infrastructure can attract automated brute-force attacks.

Continuous monitoring of authentication logs and early detection of abnormal login activity are critical for preventing unauthorized access.
